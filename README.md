## Para que serve a aba "Projects" no GitHub?

A aba **Projects** (Projetos) no GitHub é uma ferramenta de **gerenciamento de tarefas e organização de trabalho** integrada diretamente ao repositório ou à organização. Com ela, é possível:

### 📋 Principais funcionalidades

- **Criar quadros Kanban** — organize tarefas em colunas como "A fazer", "Em andamento" e "Concluído", facilitando a visualização do progresso.
- **Vincular issues e pull requests** — associe itens do quadro diretamente a issues abertas ou pull requests, mantendo tudo centralizado.
- **Acompanhar o progresso** — tenha uma visão clara do status de cada tarefa e identifique gargalos no fluxo de trabalho.
- **Colaboração em equipe** — atribua tarefas a membros específicos da equipe, definindo responsáveis e prazos.
- **Filtros e visualizações** — filtre e agrupe tarefas por labels, responsáveis, milestones ou status personalizados.
- **Automações** — configure ações automáticas, como mover um cartão para "Concluído" quando um pull request é mesclado.

### 🎯 Quando usar?

O Projects é especialmente útil para:

- Planejar sprints e ciclos de desenvolvimento.
- Organizar o backlog de tarefas e melhorias.
- Gerenciar lançamentos de versões (releases).
- Coordenar o trabalho entre diferentes membros da equipe.
- Rastrear bugs e solicitações de funcionalidades.

### 🔗 Relação com Issues e Pull Requests

Os cartões dentro de um projeto podem ser simples notas de texto ou estar vinculados a uma **issue** ou **pull request** existente no repositório. Isso permite que o status do item no projeto seja atualizado automaticamente à medida que o trabalho avança.

Em resumo, a aba **Projects** transforma o GitHub em uma plataforma completa de gerenciamento de projetos, eliminando a necessidade de ferramentas externas para equipes que já utilizam o GitHub para hospedar seu código.
